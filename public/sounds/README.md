# Windows 95 Sound Effects

This folder should contain the following sound files for the authentic Windows 95 experience:

## Required Sound Files:

1. **click.wav** - Single click sound (icon selection)
2. **double-click.wav** - Double click sound (icon activation)
3. **window-open.wav** - Window opening sound
4. **error.wav** - Error sound (for invalid actions)
5. **startup.wav** - System startup sound

## Sound File Specifications:

- **Format**: WAV (recommended) or MP3
- **Sample Rate**: 22050 Hz or 44100 Hz
- **Bit Depth**: 16-bit
- **Channels**: Mono or Stereo
- **Duration**: 0.1 - 0.5 seconds (short and crisp)

## Where to Find Windows 95 Sounds:

1. **Archive.org**: Search for "Windows 95 system sounds"
2. **YouTube**: Windows 95 sound effect compilations
3. **Sound Libraries**: Free sound effect websites
4. **Emulators**: Extract from Windows 95 emulator installations

## File Structure:

```
public/sounds/
├── click.wav
├── double-click.wav
├── window-open.wav
├── error.wav
├── startup.wav
└── README.md
```

## Alternative: Generate Your Own

You can also create simple beep sounds using online tone generators or audio editing software.

## Note:

If sound files are not found, the application will continue to work without sound effects, but will log warnings to the console.
