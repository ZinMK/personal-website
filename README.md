# Retro Portfolio Website

A Windows 95-inspired portfolio website that combines a classic desktop aesthetic with modern web technologies. This project features a fully interactive desktop environment where users can drag windows, view projects, and interact with an AI voice agent.

## Functionality: Meet Greg

The core feature of this portfolio is **Greg**, a voice-powered AI agent. Greg is trained on my professional background and can answer questions about my resume, skills, and experience.

**How to use Greg:**

1. Locate the **Greg Voice Agent** icon on the desktop.
2. Click to open the window.
3. Select **Start Call** to begin a voice conversation about my work.

## Tech Stack

This project is built using the following technologies:

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **shadcn/ui**
- **VAPI** (Voice AI platform)
- **Capacitor** (Mobile framework)
